# عرض مكوّنات الكمبيوتر التفاعلي

## رابط المعاينة

https://ahmedshabban1412008-ux.github.io/ahmed-shaban/

الموقع منشور من المستودع العام `ahmedshabban1412008-ux/ahmed-shaban` باستخدام GitHub Pages.

## تعديل النصوص

1. افتح `index.html` بمحرر نصوص.
2. ابحث عن `const DETAILS`.
3. عدّل `name` للعنوان، و`intro` للشرح، و`parts` للأجزاء، و`refs` للمراجع.
4. اترك `hardware-exploded-view.png` بجانب `index.html`.

## نشر التعديلات

ارفع `index.html` المحدّث إلى جذر المستودع على GitHub، ثم اعمل Commit. GitHub Pages يعيد نشر الموقع من فرع `main` تلقائيًا.

## تشغيل نسخة محلية

افتح `index.html` بمتصفح Chrome أو Edge. العرض والصورة يعملان محليًا من دون إنترنت؛ لكن فتح المراجع يحتاج اتصالًا.
