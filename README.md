# عرض مكوّنات الكمبيوتر التفاعلي

## تعديل العرض

- افتح `index.html` بمحرر نصوص.
- ابحث عن `const DETAILS` لتعديل عناوين المكوّنات والشرح والأجزاء والمراجع.
- عدّل `accent` و`focus` و`shift` إذا أردت تغيير لون التمييز أو مكان الزوم.
- اترك `hardware-exploded-view.png` بجوار `index.html`؛ الصفحة تستخدم الصورة المحلية.

## تشغيله من جهازك

افتح `index.html` بمتصفح Chrome أو Edge. لا يحتاج تشغيل العرض إلى إنترنت، لكن فتح المراجع يحتاج اتصالًا.

## نشر رابط ثابت للفريق باستخدام GitHub Pages

1. سجّل الدخول إلى GitHub.
2. أنشئ مستودعًا عامًا باسم `computer-components-presentation`.
3. ارفع الملفات الثلاثة الموجودة في هذا المجلد إلى جذر المستودع: `index.html` و`hardware-exploded-view.png` و`README.md`.
4. من Settings ثم Pages، اختر النشر من الفرع `main` والمجلد `/(root)`، ثم احفظ.
5. بعد انتهاء النشر، سيعرض GitHub Pages رابط الموقع. أرسله للفريق على واتساب.

بعد تعديل النص محليًا، ارفع `index.html` المحدّث إلى المستودع نفسه ليظهر التغيير في الموقع.
